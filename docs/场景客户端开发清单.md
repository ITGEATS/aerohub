# 场景客户端开发清单

2026-11-14：基于当前 ProjectAirSim 临时客户端梳理。本文记录普通功能开发问题，完成状态以实际实现和验证为准。2026-11-14 补充：显示与对接接口统一归入插件修改；按插件、UE 场景本身、manager 机制三类管理。首轮聚焦显示，其余分类作为待办，不自动扩大实施范围。

原生能力与来源统一查阅 [ProjectAirSim 开发参考](ProjectAirSim原生显示接口核查.md)。插件开发前先核对该文档，版本或能力结论变化时同步更新。

## 插件：显示与接口

- 明确区分显示计时状态、遥测状态与实际任务状态；不得用计时器 READY/TRACKING 表示 PX4、AS2 或任务已就绪。
- 标明速度来源为仿真 ground truth，时间为包含暂停的墙钟时间。
- 遥测缺失或过期时，数字、指针和彩色速度条一致失效；历史峰值与当前读数分别表达。
- 优化信息层级、长车辆名、窗口尺寸、亮暗背景下的可读性与场景遮挡。
- 设计全局俯视、单机跟随、观察对象选择及多机实时质心跟踪，并分别验证。
- 后续显示目标、规划轨迹、实际轨迹及车辆对应关系；明确数据源、坐标和时间语义。
- 静态预览覆盖正常与异常状态；UE 实际窗口验证布局、更新和失效行为，打包程序另行验证。

### 对接接口

- 汇总仿真、传感器、PX4、AS2 与任务状态；每项注明来源和新鲜度，缺失时显示未知。
- 任务状态来自真实任务生命周期；显示计时接口保持其现有职责。
- 核查遥测 RPC 失败退出、重连和原因呈现，避免仅显示空读数。
- 保持四方职责：工作站任务调用算力板能力，高频执行留在算力板。
- 建立客户端验收矩阵：首次启动、依赖缺失、attach、重复启动、断连恢复、重新 Play、多机观察、退出及打包运行。


## UE 场景本身

- 梳理场景包入口、车辆与传感器配置、出生位置、资源和版本依赖。
- 统一呈现场景包 manifest 与已有校验结果，先核对现有格式再扩展。
- 核查编辑器与打包场景的一致性、插件加载和目标环境启动。
- 明确世界重置、车辆重载、相机操作的行为与影响。

## Manager 机制

- 收束选择场景、检查依赖、启动或连接、观察、退出的完整会话流程。
- 明确启动中、运行、部分失败、断连、退出等状态与恢复操作。
- 处理重复启动、残留辅助进程、Play 重启、部分启动失败及重试。
- 区分进程存活、端口可达与数据持续更新，不把存活等同于就绪。
- 清楚呈现自有和外部进程的管理边界，区分断开、停止、退出和重置。

## 本分支交付状态（2026-11-15）

### 已完成

- 开发资源导航：通过 resources 定位 ProjectAirSim 上游源码、UE 工程、运行包和原生 Python 环境；记录原生显示/接口能力、锁定版本和源码依据。setup_client.py 支持从配置资源进行原生 SDK editable 安装及检查。
- 小窗口代码接口：ImageWindows.show/close 按代码列表自动排列、整组替换/关闭重开；receive 按真实数据源路由。不增加窗口配置文件。真实重复启停遇到原生 GUI join 阻塞后，采用每组独立子进程隔离，三轮真实图像关闭重开验证通过；Esc 后恢复仍未单独验收。
- 主视口与 HUD：车辆身份、仪表、状态、墙钟和速度峰值随主观察车辆切换；状态 IDLE/RUNNING/FINISHED，未知显示 --；移除右下重复状态。保留原速度表和紧凑细边框主栏，车辆/相机原名/图像类型采用不同视觉层级，提高 WALL 和相机行可读性。
- 观察适配：Tab 轮换已登记的 streaming captures，G 切换 Global；保留 ID __global__ 显示为 Global/TopCamera。每帧按全部车辆实时质心正上方垂直俯视，调整观察距离。不修改上游源码或读取私有状态。
- 动态文字：左右双标题，左暖金、右亮青，共用中文粗体、字号、描边和边距，分别对齐屏幕两侧；中央提示支持覆盖、持续时间、清空与三行换行。文字在 HUD 下层绘制。固定样式由插件维护，运行时只更新内容。标题及双标题视觉已获用户认可。
- 统一扩展 RPC：ProjectAirSimExtensionClient 负责本项目对 ProjectAirSim 新增的所有 RPC，当前方法覆盖标题、提示、观察视图和生命周期；纯 Python 标准库，明确超时及传输/协议/服务端异常，不自动重试。客户端不接收终端命令，控制程序直接调用。
- 生命周期：start_run/finish_run/reset_run 各发一次 ControlRun，由插件同一回调完成指定车辆状态及单调墙钟计时更新；开始新一轮清峰值，结束保留峰值，重置清零；重复调用稳定，IDLE 下 finish 拒绝。旧 SetRunState/ControlTimer 保留兼容，不与新业务入口混用。
- 生命周期和显示接口仅改变观察状态，不启动算法、不解锁或控制飞行。

- 运行环境保留 UE IO dispatcher handled ensure、可选 PixelStreaming 变量和初始出生几何警告，未声称修复。
